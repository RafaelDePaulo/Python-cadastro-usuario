# Projeto: Sistema de Cadastro de Usuários em Python

Meu segundo projeto em Python! Um sistema completo que roda no terminal para gerenciar cadastros de usuários.

## O que faz
- Cadastra novos usuários (nome, email, idade)
- Lista todos os usuários cadastrados
- Busca usuário por email
- Remove usuário com confirmação
- Salva dados automaticamente em arquivo

## Como usar
1. Tenha Python instalado
2. Baixe o arquivo main.py
3. No terminal: python main.py

## O que aprendi
- Como usar dicionários em Python
- Como salvar e carregar dados em arquivo JSON
- Como fazer validação de dados
- Como usar o módulo OS para verificar arquivos
- Operações CRUD completas

## Tecnologias
- Python
- JSON
- Módulo OS
